CARA MENJALANKAN
1. Ekstrak folder portfolio-website.
2. Buka file index.html dengan browser (klik dua kali).
3. Atau buka folder di VS Code lalu gunakan ekstensi Live Server.

STRUKTUR FILE
- index.html     : halaman utama (Home)
- About.html     : profil dan identitas
- Skills.html    : daftar kemampuan
- Portfolio.html : daftar project
- Contact.html   : kontak dan form
- css/style.css  : satu-satunya file CSS
- images/        : foto profil dan thumbnail project

CATATAN
- Ganti images/profile.jpg dengan foto asli Anda (nama file harus sama).
- Ganti email@example.com dengan email asli di semua halaman.
- Ganti link GitHub dengan akun GitHub Anda.
